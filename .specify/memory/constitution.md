# Todo In-Memory Python Console Application Constitution

## Core Principles

### I. Spec-Driven Development Authority
Specifications are the single source of truth for all development. Code must always be generated from specs. Incorrect behavior requires spec refinement, never manual code edits.

### II. In-Memory Operation Only
The application must store tasks only in memory with no persistence to files or databases. All data is ephemeral and exists only during runtime.

### III. Console-First Interface
All application functionality must be accessible through a command-line interface. No GUI, web interface, or external API connections are permitted.

### IV. Five Core Features (NON-NEGOTIABLE)
The application must implement exactly these five features: Add Task, View Task List, Update Task, Delete Task, Mark Task Complete/Incomplete. All features must be accessible via console commands.

### V. Python-Only Implementation
Implementation must use Python 3.13+ with standard library only. No external packages or frameworks beyond what's necessary for basic console interaction.

### VI. Minimalist Architecture
Application must follow clean code principles with clear function boundaries. Implementation should be simple and avoid unnecessary complexity or abstractions.

## Scope Constraints

Phase I is standalone with no persistence (no files, no database). Console-based interaction only. No web, no cloud, no agents. No advanced or intelligent features beyond the five core requirements.

## Development Workflow

Every change must follow this loop without skipping steps: Write or refine a Markdown specification → Generate an implementation plan → Break the plan into tasks → Generate code → Validate against the spec → Refine spec and regenerate if needed. All code must be generated by AI agents; humans must not write or edit code directly.

## Governance

This constitution supersedes all other practices. All implementations must verify compliance with these principles. Amendments require documentation and approval. This constitution was ratified for the Todo In-Memory Python Console Application hackathon project.
